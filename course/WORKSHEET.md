## Question

What single question is this experiment answering?

## Prediction made before running

Include:

- Expected direction of the primary metric
- Expected visual change
- Expected model-specific diagnostic
- What result would falsify the prediction

## Controlled variables

List what was intentionally held constant.

## Independent variable

Name the one thing deliberately changed.

## Results

Record the exact relevant numbers and figure paths. Do not write only
“better” or “worse.”

## Interpretation

Explain the causal story supported by the evidence. Separate observations from
inferences.

## Failure checks

- Did train and validation behavior diverge?
- Did the model use its latent representation?
- Did any loss term dominate because of scale?
- Was the intended artifact/checkpoint inspected?
- Could this be seed noise?

## Decision

State one of:

- Hypothesis supported provisionally
- Hypothesis falsified
- Evidence inconclusive
- Implementation invalid; rerun after correction

## Next question

What uncertainty should the next experiment reduce?
